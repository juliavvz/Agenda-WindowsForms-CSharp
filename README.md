# 📇 Gerenciador de Contatos (Agenda) - Windows Forms & OOP

Aplicação desenvolvida em **C#** com interface gráfica (**Windows Forms**) para o gerenciamento de contatos pessoais, estruturada com base em princípios estritos de Orientação a Objetos (Classes Data, Telefone, Contato e Contatos).

---

## 🚀 Funcionalidades da Aplicação
- **Adicionar Contato:** Cadastro de nome, e-mail, data de nascimento e múltiplos telefones (com definição de telefone principal).
- **Pesquisar Contato:** Consulta de contatos existentes na agenda.
- **Alterar Contato:** Atualização de dados cadastrais.
- **Remover Contato:** Exclusão de registros da lista.
- **Listar Contatos:** Exibição geral de todos os contatos salvos.

---

## 💻 Como Executar (No Notebook)
1. Certifique-se de ter o **Visual Studio** instalado com a carga de trabalho para *Desenvolvimento para Computador .NET (Windows Forms)*.
2. Clone o repositório ou abra os arquivos em um novo projeto Windows Forms Application.
3. Compile e execute a aplicação.
